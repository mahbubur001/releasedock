What's new in this layout

  • Products in the sidebar with their WordPress.org icon, version and a short state line. Pills show ↑ local changes, ↓ new commits on the server, or ! for a problem (e.g. SVN login failed).
  • Freshness under the title: "Refreshed 3 minutes ago · r3822482". It turns orange with Refresh required when stale (try "Stale data").
  • Four tabs per product: Overview (next action, working copy, directory status), Activity, Releases, Files.
  • Activity: commits to this plugin only, grouped by day with sticky headers, a timeline rail, file chips, release tag chips and unread dots. The data is Radius Booking's real SVN log.
  • Releases: every tag, with the Stable tag marked and Compare / Restore on each row.
  • Files: trunk, assets and tag names with local and server status. Only changed files are shown by default, with a hidden count.
  • Transcript (toolbar button, ⌥⌘0): the exact svn commands with exit codes and timings; passwords are never shown.
  • Release review: a step list, side-by-side image compare for assets, an inline code diff and message History/Templates. The banner warning is real: Radius Booking's banner-772x250.png is 1544×500.
  • Empty and error states: one icon, one sentence, one action.
  • Overview, New Release and History stay at the top of the sidebar; the Products page becomes the product list itself.
